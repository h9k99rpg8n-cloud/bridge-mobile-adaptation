# Bridge Version Analysis

## Objetivo

Analizar qué versión de bridge. es mejor para adaptar a móviles.

## Posibles bases

### bridge. clásico

Ventajas:
- Más ligero.
- Menos complejo.

Desventajas:
- Menos moderno.
- Puede tener peor soporte móvil.

### bridge. v2

Ventajas:
- Web/PWA.
- Mejor arquitectura moderna.
- Mejor soporte futuro.

Desventajas:
- Más complejo.
- Interfaz pesada para móviles.

## Decisión inicial

Actualmente parece mejor usar bridge. v2 como base para adaptación móvil.
