# Plan Mobile Adaptation

## Objetivo

Hacer que bridge. sea cómodo de usar desde móviles.

## Problemas detectados

- Botones pequeños en móviles.
- Paneles incómodos en vertical.
- JSON difícil de editar desde teclado móvil.
- Problemas de importación/exportación en Safari.
- Experiencia táctil limitada.

## Primera fase

- Analizar interfaz actual de bridge.
- Crear mockups mobile-first.
- Diseñar barra rápida JSON.
- Mejorar navegación táctil.
- Investigar soporte PWA en Safari.

## Segunda fase

- Crear prototipos CSS móviles.
- Probar layouts responsive.
- Ajustar sidebar y paneles.

## Tercera fase

- Testing real en iPhone y Android.
- Optimización.
- Documentación.
