# Contribuir a Bridge Mobile Adaptation

Este proyecto busca adaptar la experiencia de bridge. para navegadores móviles, especialmente iPhone/Safari y Android/Chrome.

## Reglas del proyecto

- Mantener el proyecto abierto bajo GPL-3.0.
- Documentar cualquier cambio tomado o inspirado directamente en bridge.
- Priorizar cambios de interfaz y experiencia móvil antes de tocar la lógica principal.
- Probar en dispositivos reales cuando sea posible.

## Flujo recomendado

1. Crear una rama nueva para cada cambio.
2. Hacer cambios pequeños y fáciles de revisar.
3. Probar en navegador móvil.
4. Documentar resultados en `docs/testing-log.md`.

## Objetivo inicial

Antes de modificar bridge. directamente, este repositorio documentará problemas móviles, plan de adaptación y prototipos de interfaz.
